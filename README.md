## 📌 Project Overview

Brew & Bean Café is a responsive, three-page website designed for a local café business. It provides information about the café, displays its menu, and allows visitors to fill out a contact form.

The website is designed with a warm café-inspired color palette and a clean, user-friendly layout.

## ✨ Features

- Responsive navigation bar with a mobile hamburger menu.
- Hero section introducing the café.
- Why Choose Us section with feature cards.
- About Us section with an image and hover zoom effect.
- Customer Reviews section.
- FAQ section using Bootstrap Accordion.
- Menu page with six product cards, prices, and badges.
- Contact form with input validation.
- Bootstrap Modal displaying a thank-you message after form submission.
- Responsive footer with contact information and opening hours.

## 📄 Website Pages

### 1. Home Page — `index.html`

Introduces the café and includes the Hero, Why Choose Us, About Us, Customer Reviews, FAQ Accordion, and Footer sections.

### 2. Services Page — `services.html`

Displays six café products with descriptions, prices, and order buttons.

### 3. Contact Page — `contact.html`

Contains a contact form with name, email, phone number, product selection, message, and checkbox fields.

A Bootstrap Modal displays a thank-you message when the form is submitted successfully.

## 🚀 How to Run the Project

1. Download or clone the project folder.
2. Open the folder in Visual Studio Code.
3. Open `index.html` in a web browser.
4. Use the navigation bar to visit the Services and Contact pages.

An internet connection is required to load Bootstrap from the CDN.

## 📱 Responsive Design

The website uses Bootstrap's responsive grid system to adapt its layout to mobile phones, tablets, and desktop screens.

## ⚠️ Notes

- Product prices and business contact details are sample information.
- The contact form demonstrates frontend validation and a thank-you modal. It does not send messages to a server or save form data to a database.
